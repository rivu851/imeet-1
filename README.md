# IMEET 2026

Landing page for IMEET 2026, the departmental fest of the Department of Information Technology, RCCIIT, Kolkata.

Built with Next.js, Tailwind CSS, GSAP, Framer Motion and Lenis.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Structure

- `src/app` - layout, global styles and the page
- `src/components/imeet` - page sections (hero, about, pillars, events, countdown, gallery, register, footer)
- `src/components` - reusable animated pieces (text loop, stroke text, scroll stack)
- `public/imeet`, `public/assest` - artwork, video and images
- `public/fonts` - headline font (personal-use licence, see `Readme.txt`)
